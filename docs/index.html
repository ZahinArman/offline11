ShutCap 2.1.0

ShutCap turns your Windows PC off once each night, at a time that you choose. It never locks you out.

Before you install

  1. Windows can show a warning.

    The setup file is not code-signed, so SmartScreen can stop it. Click More info, then click Run anyway.

  2. Practice mode is on at first.

    ShutCap shows all warnings, but it does not turn off the PC. When you are ready, open Settings and turn off Practice mode.

What is new in 2.1.0

  • One new design. All windows look the same. They follow the light or dark mode of Windows.

  • Fewer pop-ups. Approximately 30 pop-ups are now 3 alerts: a warning card, the curfew window, and a small countdown.

  • Faster setup. Set the time on a dial. Then make sure that the three evening times are correct.

  • Choose the install folder. Setup always makes its own ShutCap folder in the place that you choose.

All changes in 2.1.0

Alerts

  • Reminders only play a sound. If phone alerts are on, they also send a push notification.
  • Confirmations open in the same window. ShutCap asks only before it turns off the PC or deletes data.
  • When you save, ShutCap shows the new state. It does not show a message.
  • Errors show next to the field that is wrong.

App

  • Settings and History are in the main window.
  • If ShutCap is already open, a second start shows the open window.
  • Text is sharp on high-resolution screens. Windows 11 shows rounded corners.
  • Test mode runs next to the real app.

Install and uninstall

  • Setup does not install into a folder that has other files in it.
  • The uninstaller finds the real install folder. It can keep your settings.
  • ShutCap now needs Microsoft Edge WebView2. Windows 11 has it. On Windows 10, get WebView2 from Microsoft.

Uninstall

  • Open Settings > Apps > Installed apps. Select ShutCap. Click Uninstall.

Questions

What is ShutCap?

ShutCap is a free Windows app that turns your PC off once each night, at a time that you choose. It shows warnings before the shutdown, and it never locks you out.

How do I make my Windows PC shut down automatically at night?

Install ShutCap and set your shutdown time on the dial. By default, ShutCap warns you 45 minutes and 25 minutes before. 15 minutes before, it shows the curfew window and a countdown. At your time, Windows turns off the PC.

Does ShutCap force my apps to close?

No. ShutCap runs the Windows command shutdown /s /t 60, without /f. Windows gives your apps 60 seconds to close. ShutCap does not force them to close.

Can I cancel tonight's shutdown?

Yes. In the curfew window, click I have an emergency, write a reason, and click Cancel tonight's shutdown. ShutCap cancels tonight only and writes the reason to History. You can also click Cancel shutdown in the ShutCap window.

Will ShutCap lock me out of my PC?

No. ShutCap turns off the PC one time each night at most. If you turn the PC on again after the curfew starts, ShutCap does nothing more that night.

Is ShutCap free, and does it collect data?

ShutCap is free and open source, with the MIT licence. It has no account, no telemetry, and no cloud service. Phone alerts through ntfy.sh are optional and off by default.

What do I need to run ShutCap?

You need Windows 10 or Windows 11 and Microsoft Edge WebView2. Windows 11 includes WebView2. You do not need administrator rights.

How do I uninstall ShutCap?

Open Settings > Apps > Installed apps, select ShutCap, and click Uninstall. The uninstaller removes the app, its shortcuts, and its start-up entry. It can keep your settings.
